Xray Setup / OpenWrt

Автоматическая установка и настройка Xray на роутере за одну команду

Base64-encoded VLESS подписка от вашего провайдера

Введите корректный URL подписки

Команда для роутера

Вставьте в SSH-сессию на роутере и нажмите Enter

  1. Подключитесь к роутеру по SSH
    Откройте терминал и выполните ssh root@192.168.1.1
  2. Вставьте ссылку на подписку выше
    Нажмите «Сгенерировать команду» — получите готовую строку
  3. Скопируйте и выполните команду на роутере
    Скрипт сам скачает Xray, настроит конфиг и запустит прокси
  4. Проверьте работу
    wget -qO- --proxy socks5://127.0.0.1:1080 https://ipinfo.io/ip
  1. SOCKS5 — 127.0.0.1:1080 — для браузеров и приложений
  2. HTTP — 127.0.0.1:1081 — HTTP-прокси
  3. TProxy — 0.0.0.0:12345 — прозрачный прокси для iptables
Xray-core  ·  Работает на OpenWrt 22.02+ (BusyBox ash)
